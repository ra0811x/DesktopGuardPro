## 发布门槛

每个阶段完成后，以下检查必须全部通过：

- 针对新增或修复行为的单元测试和集成测试。
- 权限拒绝、服务重启、睡眠恢复、磁盘满、队列溢出和设备拔除场景测试。
- Windows 10 1809 与 Windows 11 x64 实机验证。
- 默认隐私设置、显式授权、审计策略恢复和导出脱敏验证。
- MSI 安装、升级、重启、卸载、回滚、签名和校验回执验证。
