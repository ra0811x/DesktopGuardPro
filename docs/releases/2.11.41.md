# Desktop Guard Pro 2.11.41 发布说明

`2.11.41` 处理临时键鼠锁定无法稳定完成解锁，以及密码窗口打开后可以操作其他
桌面组件的问题。本版已完成构建、Raymond 证书签名和 GitHub 发布。

## 修复内容

解锁热键和密码窗口使用收紧后的状态与输入边界。

- `Ctrl+Alt+U` 等已保存组合键在钩子回调内原子进入验证态。
- 重复热键不会打开第二个密码窗口。
- 验证期间所有鼠标输入保持阻断。
- 只有前台密码输入框接收密码字符、编辑键、回车和取消键。
- Tab、Alt、Win、功能键和组件外键盘输入保持阻断。
- 错误密码在原窗口内提示，输入焦点返回密码框。
- 验证成功后立即解除并卸载钩子，服务等待代理停止确认后清除任务。
- 取消、关闭或验证失败会恢复锁定。

快捷键仍按已保存规则配置，回归使用 `Ctrl+Alt+U`，没有把 U 写死为唯一主键。
