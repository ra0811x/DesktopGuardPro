# Desktop Guard Pro 2.11.42 发布说明

`2.11.42` 修复代码审查确认的六处缺陷，覆盖保护会话、活动采集、程序维护和
报告导出。本版提供 Raymond 证书签名的 Windows x64 MSI。

## 修复内容

修复保留原有七页界面、临时键鼠控制和指定旧证书迁移规则。

- 暂停恢复先保存可启动状态，再确认采集管线；失败回退核对会话与修订，
  旧请求不能覆盖替代会话或并发修改。
- 仅开启用户会话活动时，空服务端采集器列表仍保留事件写入管线。
- 发布与安装清单登记 WinUI 程序集、依赖和资源。独立部署与升级处理完整
  文件集，升级失败恢复旧文件和清单；未登记的既有文件保留。
- 活动汇总绑定会话及修订，暂停、切换和策略变化清理旧计数与窗口信息，
  服务拒绝过期上报。
- 报告中的进程映像路径遵循对象省略、仅名称及完整路径选项。
- 局部报告从同一完整性验证快照读取最新人工处置状态，证据保持所选范围。

源码实现与复现证据见[代码审查记录](../reviews/code-review-2026-10-08.md)。
旧安装清单缺少 `runtimeFiles` 时仍可加载，新清单校验登记文件的大小和摘要。

## 验证范围

六项缺陷纳入正式回归，边界覆盖并发修订、失败回退、过期活动、文件篡改和完整回滚。
Go 回归、vet、模块校验、相关 race、checkptr、原生状态与结构、组件构建、
MSI 门禁及 WiX/ICE 检查通过。全包回归排除可能被已安装代理占用的单实例测试。

实际 MSI 版本与回执一致，510 个打包文件经只读解包核对，内嵌清单登记四组件
和 505 个运行文件。签名、时间戳、原生版本与应用清单均通过检查。

未安装 MSI、启动真实输入控制或改动运行数据。目标设备安装升级、真实键鼠、
窗口交互和远程输入仍需实机验收。完整记录见[最新验证记录](../verification/current.md)。
