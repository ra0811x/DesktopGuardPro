# Desktop Guard Pro 2.11.40 发布说明

`2.11.40` 修复旧测试签名版本切换到 Raymond 签名时的 MSI 安装失败。
本版已完成构建、签名和校验，并作为 GitHub 最新版本发布。

## 修复内容

MSI 安装事务允许经过核对的单向证书迁移。

- 已安装旧版直接升级，以及卸载旧版后保留数据再安装，均可使用相同迁移规则。
- 只接受指定旧测试证书迁移到当前 Raymond 证书，以证书 SHA-256 核对身份。
- 保留安装所有者、活动会话、组件签名和事务内签名者检查。
- 保留原安装清单、策略及备份回滚机制，迁移失败时可恢复旧状态。
- 其他证书、仅名称相同的证书以及反向迁移继续拒绝。

该迁移作用于 MSI 安装事务。独立维护程序的 `upgrade` 命令保持原发布者一致性规则。
