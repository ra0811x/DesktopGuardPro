# Desktop Guard Pro 2.11.39 发布说明

`2.11.39` 修复 Windows 键鼠回调指针问题，完成源码和交付目录整理，
并将四个程序及 MSI 的签名者更新为 `Raymond`。保留 WinUI 3 原生界面。

## 更新内容

本版包含以下修复与整理。

- 键盘和鼠标回调直接接收 Windows 指针，消除整数地址回转引起的
  checkptr 失败，保持物理输入阻断、注入输入放行和密码解锁行为。
- Go 模块移入 `backend/`，原生界面和状态测试移入 `frontend/`；构建脚本、
  资源路径和开发文档同步更新。
- 删除退出发布链的 Vue/Wails 界面、无效工具和多余依赖，保留维护程序
  使用的 `appbridge` 与 `desktop` 共享模块。
- 服务、代理、原生界面、维护程序和安装包统一使用 `CN=Raymond` 签名，
  并附带 SHA-256 时间戳。

## 安装兼容范围

本版可用于新安装。维护程序核对已安装版本与新组件的签名身份，
旧测试签名版本无法直接原位升级到本版；保留数据卸载仍会保留旧安装清单，
也会保留该限制。既有数据的签名身份迁移需单独处理。
