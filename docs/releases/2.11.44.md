# Desktop Guard Pro 2.11.44 发布说明

`2.11.44` 补齐分级设置菜单，新增主界面开机自启动、托盘偏好、自动刷新与默认
报告格式，并处理界面早于后台服务启动时的初始化等待。正式包沿用已校验的
2.11.44 本地体验 MSI，使用 Raymond 证书签名并附带时间戳。

## 设置菜单

普通与紧凑布局提供相同的四组子菜单，保存后的开关保持同步。

- **常规与启动**：开机自启动（登录后）、自启动时收起到托盘、关闭窗口时收起
  到托盘、自动刷新服务状态，以及 Windows 启动应用管理入口。
- **保护与采集**：四种模式、五类采集模块详情、监控目标与递归、排除规则。
- **临时输入控制**：控制规则、输入设备、本地密码与恢复码、凭据删除。
- **数据与报告**：会话保留、敏感字段与报告设置、默认 HTML、Markdown 或 JSON 格式。

**关于 Desktop Guard Pro** 显示程序版本。模式、采集、凭据和报告入口复用已有
处理流程，保留保存、确认和身份验证规则。

## 开机启动与托盘

主界面自启动开关仅影响当前用户。开启后，在该用户进入 Windows 桌面时运行
主界面；后台服务继续按系统的自动启动配置运行，交互代理的安装启动项保持独立。
自启动运行主界面，保护会话和临时键鼠锁定由你在仪表盘启动。

界面初始化最多尝试连接服务六次，失败间隔 5 秒。连接成功后读取初始配置，
平时的状态轮询保留正在编辑的配置。退出界面会取消启动等待。

托盘支持单击或双击恢复窗口，右键菜单提供打开与退出。Explorer 重启后重建
图标，重建失败时显示窗口。托盘不可用时保持窗口可见，文件菜单或托盘的显式
退出关闭界面。普通启动显示窗口，自启动时收起与关闭时收起分别配置。

用户偏好保存在本机并在重新打开后恢复。写入失败会保留旧文件并提示原因。
默认保持界面自启动关闭、两项托盘收起关闭、自动刷新开启、报告格式 HTML。
默认报告格式不会自动开启敏感字段。

## 安装与升级

本版包含 2.11.42 的六项修复，沿用完整运行文件校验及指定旧签名证书迁移规则。
MSI 能识别较早版本，包括本地 2.11.43 体验包。升级保留已有界面启动开关；
卸载按已验证安装所有者清理匹配当前安装路径的界面启动项。

安装或升级前结束正在进行的保护会话并关闭主窗口。Windows 启动应用管理
可以独立禁用界面启动项，相关入口位于 **设置 → 常规与启动**。
