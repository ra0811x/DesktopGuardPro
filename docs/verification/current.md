# Desktop Guard Pro 最新验证记录

本记录核对 2026 年 9 月 30 日发布的 `2.11.41`。修复范围为临时键鼠
锁定的热键状态、密码窗口输入隔离，以及验证成功后的钩子停止确认。

## 问题复现

旧实现把验证态作为全局输入放行状态。模拟 Windows callback 的回归显示，密码窗口
打开后普通键盘、物理鼠标和注入鼠标都会传递到桌面。热键回调只发送异步通知，
不会同步锁定验证态；重复按键可以再次发出请求。

服务在凭据验证成功时立即清除临时任务。代理随后发送的停止确认无法再关联原控制
ID，钩子的解除、卸载和服务任务清除没有形成同一条确认链。

新增测试在修改实现前分别失败，错误包括：

- 验证态普通键盘返回放行。
- 物理和注入鼠标在密码窗口期间返回放行。
- `Ctrl+Alt+U` 后状态仍为 protecting。
- 验证成功后代理没有立即发送 stopped。
- 服务在代理停止确认前已经清除控制 ID。

## 修复行为

热键和连击触发通过原子状态转换进入验证态。只有首次从 protecting 转为 verifying
的请求会打开窗口，重复按键不再创建第二个请求。

密码窗口注册自身窗口和密码输入框句柄。钩子同时核对前台窗口与焦点，只向该输入框
放行密码字符、编辑键、Shift、回车和取消键。所有鼠标以及 Tab、Alt、Win、功能键
和组件外键盘输入保持阻断。错误凭据改为窗口内提示，输入焦点立即返回密码框。

验证成功后，服务先把临时任务置为 stopping。代理解除并卸载钩子，再发送 stopped
确认；服务收到相同控制 ID 的确认后清除任务。取消、关闭或验证失败会恢复 protecting。

## 自动化结果

所有键鼠回归使用模拟 callback，不安装真实系统钩子。

| 检查 | 结果 |
| --- | --- |
| 钩子定向回归 | 热键单次触发、精确焦点、键盘白名单、物理及注入鼠标阻断通过。 |
| 代理定向回归 | 成功验证立即停止引擎并报告 stopped；取消和旧任务隔离通过。 |
| 服务定向回归 | stopping 状态保留到代理停止确认，过期控制和错误凭据继续拒绝。 |
| Go 其余包 | `internal/agent` 之外的全部包通过。 |
| Agent 包 | 除当前已运行代理占用单实例互斥体的测试外，其余测试通过。 |
| `go -C backend vet ./...` | 无告警。 |
| 钩子 checkptr | `-gcflags=all=-d=checkptr=2` 通过。 |
| 钩子、代理、服务相关 race | 通过。 |
| 原生状态与界面结构 | Native.Tests 和 test-native-ui-shell.ps1 通过。 |
| MSI 签名门禁及顺序 | test-msi-release.ps1 通过。 |
| WiX/ICE 与安装表结构 | test-msi-package.ps1 通过，未安装夹具 MSI。 |

`go -C backend test ./... -count=1 -timeout=120s` 的唯一失败为
`TestAcquireInteractiveAgentInstanceIsExclusiveAndRecoverable`。当前已安装代理持有产品级
单实例互斥体，使测试进程无法取得第一次所有权；相同包排除该环境相关用例后全部通过。
本轮没有停止已安装代理来规避该条件。

## 发布文件

文件位于 `releases/2.11.41/`，包括 MSI、构建回执、对应源码、Raymond 公开证书和
SHA-256 清单。构建脚本完成三个 Go 组件、WinUI 原生界面、四组件签名、清单定稿、
WiX 链接和 MSI 签名。

- MSI 大小：`107061248` 字节。
- MSI SHA-256：
  `952E9C5F4E08751164306FF99CB72B8AD164485C753B0F3BA08A925A5D8DAEA5`。
- 签名者：`CN=Raymond`。
- 证书指纹：`DC38087948CDD021FD794F0D7B6B4F5A12345AEE`。
- 时间戳：DigiCert SHA-256 RSA4096 Timestamp Responder 2026 1。

签名状态为 Valid，构建回执中的版本、指纹和 MSI 摘要一致。2.11.38 至 2.11.40
原始发布物没有覆盖。2.11.41 已发布到 GitHub，测试过程没有自动安装 MSI。

## 实机验收范围

真实物理键鼠、远程注入输入、密码窗口焦点、Ctrl+Alt+Delete、Windows 10/11
以及实际安装升级仍需在目标设备核对。自动化没有启动真实键鼠钩子。
